# 수입을 기간당 단일 숫자에서 지출내역과 대칭인 수입내역으로 전환

기존에는 사용자가 기간마다 수입을 하나의 합계 숫자로 직접 입력했다. 지출은 처음부터 건별 기록(지출내역)을 쌓고 기간별로 자동 집계하는 방식이었는데, 수입만 다른 모델을 쓰고 있었다. 실제 사용해보니 지출처럼 수입도 건별로 기록하고 싶다는 요구가 있어, 수입내역이라는 개별 기록 단위를 새로 도입하고 "수입"은 그 기간에 속하는 수입내역들의 합계로 재정의했다. 지출내역과 마찬가지로 수입내역도 날짜를 기준으로 기간에 자동 집계되며(기간별로 직접 저장되지 않음), 카테고리는 없다(수입은 종류가 적어 분류의 효용이 낮다고 판단).

기존에 기간마다 저장돼 있던 수입 숫자는 앱을 다음에 열 때 그 기간의 시작일을 날짜로 하는 수입내역 1건으로 자동 변환되고, `Period`의 `income` 필드는 제거된다(카테고리 기본값 시딩과 같은 방식의 1회성 마이그레이션).

## Consequences

- 지출은 "기간외 지출"이 메인 화면의 최근 지출 목록에 항상 보이지만, 수입은 이번 변경에서 메인 화면에 별도 목록을 두지 않기로 했다. 그 결과 아직 어떤 기간에도 속하지 않는 수입내역("기간외 수입")은 그 수입내역을 포함하는 기간을 만들기 전까지 앱 어디에도 보이지 않는다. 이 비대칭은 의도적으로 받아들인 제약이며, 필요해지면 별도로 재검토한다.
