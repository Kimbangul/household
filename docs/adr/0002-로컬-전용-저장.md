# 서버/클라우드 동기화 없이 기기 로컬 저장만 사용한다

이 앱은 스프레드시트로 관리하던 개인 가계부를 대체하는 개인용 단일 사용자 앱으로 시작한다. 서버나 데이터베이스, 클라우드 동기화 없이 기기에만 데이터를 저장하기로 했다 — 현재 요구사항이 한 사람의 로컬 기록으로 충분하고, 백엔드를 두면 인증·동기화·비용 등 불필요한 복잡도가 늘어난다.

이 결정은 되돌리기 어렵다 — 나중에 가족 공유처럼 여러 사용자가 같은 데이터를 봐야 하는 기능이 필요해지면, 로컬 전용으로 설계된 데이터 계층을 서버 동기화 구조로 다시 짜야 한다. 사용자가 "추후 초대·권한 기능을 추가할 수도 있다"고 이미 언급했으므로, 그 시점이 오면 이 ADR을 다시 열어 재검토한다.
